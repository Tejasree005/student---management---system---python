# Student Management System using Python

## About the Project
A simple Python project to manage student records and marks.

## Features
- Add student details
- View student records
- Store roll number, name, and marks
- Menu-driven program

## Technologies Used
- Python 3
- Dictionaries
- Functions
- Loops
- Conditional Statements

## How to Run
1. Install Python 3.
2. Download the student_management.py file.
3. Open a terminal.
4. Run the command:

python student_management.py
